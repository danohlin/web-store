Check rollout status:
  kubectl rollout status deploy/{{ include "web-store.fullname" . }}-backend -n {{ .Release.Namespace }}
  kubectl rollout status deploy/{{ include "web-store.fullname" . }}-frontend -n {{ .Release.Namespace }}

IMPORTANT — teardown order. The ALB and its security groups are created by the
controller, not by Terraform. Deleting the cluster or VPC first strands network
interfaces that block the VPC from being destroyed, and `terraform destroy`
then hangs for ~20 minutes before failing. Always remove this release and wait
for the ALB to disappear before destroying infrastructure:

  helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
  kubectl wait --for=delete ingress/{{ include "web-store.fullname" . }} -n {{ .Release.Namespace }} --timeout=5m
